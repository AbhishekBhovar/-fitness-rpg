POWER JOURNEY WIDGET

Install into the existing -fitness-rpg GitHub repository:

1. Upload the entire "power-widget" folder into the ROOT of the existing repository.
   Do not delete or replace the existing index.html or assets folder.
2. Commit the files.
3. Open:
   https://abhishekbhovar.github.io/-fitness-rpg/power-widget/
4. On iPhone Safari: Share > Add to Home Screen.

HOW IT WORKS
- Reads the existing Power Journey saved rankings from localStorage key: fitnessRPGv11.
- Uses the character images already stored in ../assets/.
- Automatically shows current level, current character, next unlock, progress,
  strength benchmarks ready, average strength tier, strongest benchmark,
  and the benchmark that needs the most development.
- The mantra changes with your level and deliberately encourages consistent training,
  volume, form and progression rather than attempting a PB every workout.
- The Open Power Journey button returns to the main app.

IMPORTANT
If the widget says no saved rankings were found, open the main Power Journey app,
enter/update your results and tap Calculate Rankings, then reopen the widget.
