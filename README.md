# LEVEL UP — 30 Level Athletic Build

GitHub Pages-ready PWA.

## What changed
- Expanded to 30 character levels and the final stage structure.
- Athletic strength ceilings: machine loads stop increasing once mastered.
- 10 kg assisted-chin progression (pending final machine-stack confirmation), then bodyweight and weighted chins.
- Smoothed 5K progression plus 10K requirements at Levels 29–30.
- Added cumulative mobility, jumps, plyometrics, martial arts and sparring assessment tracking.
- Added portrait-friendly "Next Level" requirement UI.
- Added 10K input and preserved the five-tab mobile navigation.
- Preserved the approved mobility/jump/plyometric demo assets and electric-blue PWA styling.

## Character artwork
Existing approved images were reused where the exact character already had a verified asset. New roster characters without a verified asset use a clean placeholder slot so no incorrect image is silently substituted.

- Replaced L14 duplicate forward-fold test with objective **Straddle Flexibility**: 90°+ seated straddle, knees straight, forearms flat between legs for 10 seconds; 1 successful hold within 3 attempts.

- Cleaned the LEVEL UP logo edge/background to remove brown corner patches.
- Replaced the Pogo Jumps demo with a cleaner, lower-border visual.
- Retains compact Spider-Man artwork and prior merged Guide fixes.

## V33 Guide visual standardisation
- Standardised Guide movement visuals to a consistent dark navy/cyan visual system.
